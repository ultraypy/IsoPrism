# IsoPrism

IsoPrism predicts within-gene isoform proportions from short-read single-cell or spatial gene-expression matrices. The implementation was previously called Competitive-TA.

Install from this GitHub repository with `pip install -e .`. Use `isoprism-predict --help` for inference and `isoprism-benchmark --help` for the five-setting benchmark.

- [Benchmark and metrics](benchmark.md)
- [Input data format](data-format.md)

The former IsoVAE model is preserved in the [legacy documentation](legacy/overview.md). IsoVAE, IsoBudget-v2 and IsoPrism are distinct models.
