# Documentation deployment guide

This guide explains how to publish the IsoVAE documentation to common documentation hosting platforms.

## Before deployment

Install documentation dependencies:

```bash
pip install -e ".[docs]"
```

Preview locally:

```bash
mkdocs serve
```

Build static files:

```bash
mkdocs build
```

The generated website will be in:

```text
site/
```

---

## Option 1: GitHub Pages

This is the simplest option if your code is hosted on GitHub.

### One-command deployment

From the repository root:

```bash
mkdocs gh-deploy
```

This creates or updates a `gh-pages` branch and publishes the documentation.

### GitHub settings

1. Open your GitHub repository.
2. Go to **Settings** → **Pages**.
3. Set source to the `gh-pages` branch.
4. The website will usually be available at:

```text
https://ultraypy.github.io/IsoVAE/
```

### Update `mkdocs.yml`

Before publishing, edit:

```yaml
site_url: https://ultraypy.github.io/IsoVAE/
repo_url: https://github.com/ultraypy/IsoVAE
repo_name: ultraypy/IsoVAE
```

---

## Option 2: Read the Docs

Read the Docs is a common platform for Python package documentation.

### Steps

1. Push your repository to GitHub.
2. Log in to Read the Docs.
3. Import the GitHub repository.
4. Choose MkDocs as the documentation tool.
5. Set the configuration file to:

```text
mkdocs.yml
```

### Optional `.readthedocs.yaml`

You can add this file to the repository root:

```yaml
version: 2

build:
  os: ubuntu-22.04
  tools:
    python: "3.10"

python:
  install:
    - method: pip
      path: .
      extra_requirements:
        - docs

mkdocs:
  configuration: mkdocs.yml
```

After each push to GitHub, Read the Docs can automatically rebuild the website.

---

## Option 3: Netlify

Netlify can host the static `site/` directory generated by MkDocs.

### Build settings

In Netlify, set:

```text
Build command: pip install -e ".[docs]" && mkdocs build
Publish directory: site
```

Then connect the GitHub repository. Netlify will rebuild the documentation after each push.

---

## Option 4: Vercel

Vercel can also serve the static MkDocs site.

### Build settings

Use:

```text
Build command: pip install -e ".[docs]" && mkdocs build
Output directory: site
```

Connect your GitHub repository and deploy.

---

## Recommended choice

For this project, the recommended path is:

1. Use **GitHub Pages** for the first public release.
2. Use **Read the Docs** later if you want versioned documentation for multiple package releases.

---

## Deployment configuration files included in this repository

This release directory already contains optional deployment configuration files:

```text
.github/workflows/docs.yml   # GitHub Actions deployment to GitHub Pages
.readthedocs.yaml            # Read the Docs configuration
netlify.toml                 # Netlify build configuration
```

Before publishing, replace `ultraypy` in `mkdocs.yml` and `pyproject.toml` with your real GitHub username and repository URL.
